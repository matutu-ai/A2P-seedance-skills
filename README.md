# A2P Seedance Skills

本仓库保存 `lingguo-seedance-master` Skill 及其演示案例。默认交付**可直接用于 Seedance 的提示词和编号素材包**；用户已授权视频制作时继续生成、审片并交付可播放文件。

## 工作流程

1. 读取用户的初始资料，区分事实、目标、限制和暂定假设。
2. 可先从适配的“八大玩法”中选择玩法类型；每个展示的玩法各附一张静态效果预览图。已选玩法直接沿用，再提出创意方向与视觉风格，展开完整方案供确认。玩法编号 1–8 与创意方向 A/B/C 分开。
3. 方案确认后，连续完成素材职责表、素材生成提示词、分镜及结构化 Seedance 主提示词。最终提示词首行写玩法，代码块内标明每个 `@素材` 的用途。下载参考图按 `图片N-用途.png` 命名，与提示词编号一致；多张参考图同时交付时用[编号打包脚本](lingguo-seedance-master/scripts/package_assets.py)校验并提供一个 ZIP 一键下载。
4. 检查事实依据、素材编号、时间轴、连续性、平台设置和提示词冲突，再交付最终版本。
5. 已获视频制作授权时，核对目标平台规则并提交生成，逐镜审片、修复、交付视频；预演与 Seedance 成片分别标注。

入口：[lingguo-seedance-master/SKILL.md](lingguo-seedance-master/SKILL.md)。使用时可显式调用 `$lingguo-seedance-master`。

## 案例

- [咖啡机新创意：功夫豆子转场到办公](cases/咖啡机-功夫咖啡豆-办公/完整提示词包.md)：玩法六效果预览图、五张已生成的编号参考图、24 秒主提示词及 7+8+9 秒分段提示词。
- [咖啡机 C：冲煮微观片](cases/咖啡机-C-冲煮微观片/提示词包.md)：沿用玩法六，以原图和两张局部参考图组织 15 秒微距广告提示词。
- [两阶段流程验收](cases/两阶段验收-气泡水/04-验收记录.md)：虚构初始资料、待确认创意方案、模拟确认后的提示词包及自检。模拟确认不代表真实客户批准。
- [气泡水广告演示](cases/气泡水广告-15秒/案例.md)：概念参考图与 15 秒分镜动态预演。预演由静态图制作，不是 Seedance 成片。

平台能力和素材引用方式会随模型及使用界面变化，实际项目按目标平台当前官方文档核对。视频制作与对外发布是不同步骤；发布仍按用户授权执行。
