# 两阶段流程验收记录

测试输入为[虚构初始资料](01-初始资料.md)，不是客户项目。第一阶段输出[创意方案](02-创意方案-待确认.md)；第二阶段以**模拟确认方向 A**为前提输出[最终提示词包](03-最终提示词包-模拟确认A.md)。没有实际请求用户确认，也没有提交 Seedance。

| 验收点 | 观察结果 |
|---|---|
| 资料先分析 | 区分概念图可见事实、需求陈述和平台暂定项；未添加真实品牌、配方或功效。 |
| 方案可审核 | 提供三种不同的玩法与风格；推荐方向 A 并展开 15 秒节拍、声音、素材和难点。第一阶段未提前输出最终视频提示词。 |
| 确认后连续交付 | 第二阶段包含素材地图、独立的微距参考图提示词、分镜、完整 Seedance 主提示词、上传顺序和自检。没有逐镜头再次确认。 |
| 提示词可执行性 | 演示平台按火山方舟 Seedance 2.0 指南使用“图片1、图片2”顺序引用；三镜头时段覆盖 0–15 秒，主提示词引用与素材地图一致。 |
| 商业与视觉约束 | 产品外观由已有概念图锁定；新增微距图只承担材质职责；准确文字留给后期，没有虚构销售事实。 |
| 工具与阶段边界 | Skill 文件结构校验通过；案例本地链接与代码块检查通过。图片2和视频均未生成，因此没有声称成片效果通过验收。 |

剩余限制：本测试只验证**方案与提示词交付流程**。实际 Seedance 出片效果、图片2生成质量及具体账号界面的参数，需要在用户提供真实项目资料并选择平台后另行验证。
