# 关卡提问模板

用户回复后才继续。字母选项需有默认推荐，减少打字。

## 关卡 0 体检摘要

```text
【资料体检】
已确认：……（出处）
目标/受众/平台：……
现有素材：……
红线：……
暂定假设：……

需要你确认的问题（最多3个，不确定就回复“按假设走”）：
1. ……
```

## 关卡 1 方向选择

（无阻塞缺口时可与关卡 0 合并：先给体检摘要，再给下面的选项；开头加一句“已排除的玩法：……，原因：……”。）

```text
基于你的资料（引用具体依据），我推荐以下玩法：

A. 【玩法名】（★★）——一句话效果。适合：……。你需提供：……。主要风险：……。
B. 【玩法名】（★★★）——……
C. 【玩法名】（★）——……
（回复“全部”可查看完整玩法库）

请一次性回复，不确定的项用默认：
1. 玩法：A（推荐）／B／C／A+辅助B
2. 视觉风格：① …… ② …… ③ ……（默认①）
3. 平台与规格：竖屏 9:16 · 15秒（默认）
4. 声音：环境声+音乐，无口播（默认）／真人口播
5. 真人脸：不出现（默认）／出现
6. 参考图：主图 / 白底图 / 场景图 / 细节图 / 多角度（默认：主图+场景图+细节图）

直接回复“A，按默认”即可。
```

## 关卡 2 参考图确认

```text
【参考图提示词】共N张：
图1：……（提示词）
图2：……（提示词）
检查要点：……

回复：确认／第X张改：……／换风格（会重做全部）
```

## 关卡 3 视频方案确认

```text
【分镜与Seedance提示词】
分镜表：……
主提示词：（代码块）
自检：……；仍需客户确认的事实：……

回复：确认／要调整：节奏／运镜／声音／某镜头（我会先说明影响范围）
```

## 变更说明

```text
你要改的是：……（归入：红线/方向/可调）
受影响：……  需重做：……  不用动：……
同意请回复“执行”。
```
