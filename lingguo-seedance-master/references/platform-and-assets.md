# 平台、素材与提示词

## 运行时平台核对

核对目标平台和模型，而非只看“Seedance 2.0/2.5”名称：可用模式；各类素材格式、大小、时长和数量；输出时长、比例、分辨率；人脸与声音输入规则；编辑、延长、首尾帧是否需要特定 role/参数；引用语法；音频是否生成或仅参考。若是 API，遵循 API 文档；若是即梦等界面，遵循界面所见规则。用户未指定平台时，最终提示词仍使用 `@图片1` 等标记素材插入位置，注明提交时以该平台插入的真实 token 替换。若目标总时长超出已核实的单次上限，写可提交的分段提示词与衔接状态；不要把总时长直接填到单次生成设置。只有进入实际生成阶段才核对费用、账号和提交状态。

火山方舟的 Seedance 2.0 指南把全模态参考、编辑、延长区分为不同任务句式；编辑/延长直接指向待处理视频，不能把它写成“参考该视频生成新片”。具体素材 token 在不同界面可能不同，最终以当前界面为准。

官方核对入口（不要从链接本身推断所有平台相同）：

- [Seedance 2.5 提示词指南，BytePlus](https://docs.byteplus.com/en/docs/modelark/seedance-2-5-prompt-guide)
- [Seedance 2.5 提示词指南，火山方舟](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)
- [Seedance 2.0 提示词指南，火山方舟](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh)
- [火山方舟视频生成任务 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)

进入实际制作时再按目标模型、接入方式和当天文档确认参数。以火山方舟现行文档为例，Seedance 2.5 的参考生视频允许 4–30 秒且最多 30 张参考图片，flash 最多 10 张；2.0 的时长和素材上限不同。该平台对含真人人脸的参考素材还有专门的上传限制及授权方案，不能仅凭“用户提供了照片”推断 API 一定接受。其他平台的产品界面可能不同。

## 素材绑定表

为实际使用的每项素材填写：`编号｜交付文件名｜类型｜主职责｜继承｜不继承｜锁定身份/场景？｜允许修改？｜作用镜头/时间｜本平台引用方式`。同一素材可有次职责，但要说明优先级；互相冲突时以真实产品/身份素材优先，场景和风格素材不得覆盖它们。

| 素材 | 典型主职责 | 常见不继承项 |
|---|---|---|
| 人物图 | 身份、五官、发型、体型、服装 | 背景、原图姿势 |
| 产品图/细节图 | 外观、颜色、结构、比例、接口、包装 | 原图杂乱背景、无关道具 |
| 场景图 | 空间布局、光线方向、环境锚点 | 不相关人物或产品 |
| 动作视频 | 动作阶段、节奏、姿态、位移 | 原人物身份、服装、背景 |
| 运镜视频 | 镜头路径、速度、构图变化 | 原主体和剧情 |
| 风格图 | 色彩、影调、材质、氛围 | 产品形状和品牌 |
| 音频 | 声音、语气、音乐节奏 | 不需要的噪声或配乐 |
| 故事板/白模 | 镜头顺序；空间、几何及运镜 | 白模材质、辅助线 |
| 首帧/尾帧 | 起始/目标状态 | 两帧以外的动作臆测 |

## 按缺口生成参考素材提示词

只为当前方案需要的素材写提示词；**一张关键帧只代表一个时间点**。单张图可用于角色身份、产品、场景、动作姿态或风格；若用户明确要故事板才做多格。动作视频、运镜视频和音频各写独立职责，不混入图片提示词。

- **人物身份图**：写明角色身份、脸型五官、发型发色、体型、服装材质；按连续性风险选择正面、45 度、侧面、全身、表情和服装细节。自然比例、均匀柔光、干净背景；避免多人、拼贴、错误肢体、夸张美颜、文字水印。真人肖像遵守实际平台要求。
- **产品图**：有真实照片时声明它是外观依据，逐项锁定可见的轮廓、颜色、结构、接口、材质、包装和标签；按镜头需要选择正面、侧面、45 度、细节、材质或使用场景。未提供的侧面、背面和内部结构不能凭生成图认定为真实；必要时给出补拍说明。没有真实照片则只生成标明“概念”的图，不暗示是真实商品。
- **场景图**：给出墙面、门窗、家具与道具位置、时间天气、主光方向、环境光、机位高度、景别和可复用空间锚点。
- **分镜关键帧**：给出主体、当前动作状态、场景、景别、构图、机位、光线与色彩；保持前后人物、产品、服装、道具一致。
- **动作姿态图**：按起始、中间、峰值、结束描述重心、手脚位置和运动方向。静态图只能辅助动作设计。
- **风格图**：明确色彩体系、主辅光、影调、景深、材质、摄影方式和氛围；避免只有“电影感”。
- **动作/运镜参考视频**：需要生成时，提示词写清主体、动作阶段、站位、运动方向、起止姿态或机位路径与速度；标明其只用于动作或镜头，不继承人物身份、服装和背景。白模预演写几何与空间关系，不要求成片材质。
- **音频参考**：写清用途是音色、配乐、环境声还是节奏，给出语言、语气、时长、节拍或声音事件；不要让音色参考自动覆盖画面角色身份，也不要把未分析的 BPM 写成精确值。

## 编译提示词

通用顺序：`玩法与生成方式 → 视频规格 → 一句话主题 → @素材职责 → 主体与场景 → 可见动作/变化 → 镜头时间轴 → 光线与色彩 → 声音/对白 → 连续性 → 必要的排除项`。第一行用 `【玩法】` 说明当前视频怎样表达、采用什么参考方式，不用空泛类型词代替具体做法。每个要上传的素材 token 必须出现在最终代码块内，并在使用它的镜头中明确作用；末尾给出按编号排列的上传清单。只写当前任务需要的字段，时间轴动作量与秒数匹配。

优化顺序：先给人物、产品、场景各定一个稳定称呼和最高优先级来源；再逐镜写起点、可见动作、接触/遮挡、镜头和结束状态；最后处理音画与排除项。参考图中的背景、姿态或时间状态若不该继承，明确排除。多镜转场要说明剪辑前后的画面如何接上，不能靠“高级转场”代替。禁止项聚焦身份漂移、产品变形、额外道具、错误文字等高风险问题，避免与正向动作重复或互相矛盾。完整目标超过单次能力或动作过密时，提供每段可独立提交的提示词与接点，不仅切分时间数字。

### 结构化视频提示词模板

结合已有 `seedance-prompt-description` 的分段习惯，企业产品片按下列结构写成**一个可复制代码块**。没有人物时用 `【产品锁定】`，没有多段续接时 `【结束状态】` 仍简要说明最后一帧；没有对应内容的段落可以省略。首行玩法编号是用户所选案例分类，不能代替下一行的实际模型/模式。

```text
【玩法】玩法N：玩法名称｜内容创意｜实际生成方式
Seedance 2.x｜Xs｜画幅｜主题｜对白/旁白状态｜BGM状态

【素材说明】
@图片1：仅用于主体外观，作用于全片；不继承原背景。
@图片2：仅用于场景布局与光线，作用于指定镜头；不继承其他产品。

【产品锁定】
可见的形状、颜色、部件与左右关系；允许的自然变化；不展示没有依据的视角或功能。

【统一摄影风格】
机位、景别、光线、材质与剪辑节奏；每镜头一个主要运镜。

【时间轴】
0-X秒｜镜头1：起始状态→动作及接触→结束状态；景别与运镜；声音。
X-Y秒｜镜头2：...

【声音】
环境声、动作音效、配乐；对白/旁白及字幕要求。

【结束状态】
最后一帧的产品、道具、场景、光线和声音；用于后续分段时写清衔接状态。

【禁止项】
与真实产品、素材职责及画面目标直接冲突的变化；未核实文字、Logo、参数按项目处理。

【最终上传素材】
@图片1、@图片2；按素材表文件名对应上传。若平台使用其他 token 格式，提交时替换为真实插入标记。
```

`@图片N` 等是交付标记；若目标平台不能直接识别该写法，提交时使用界面实际插入的素材 token。素材生成提示词单独给出，不能把未制作的素材描述当成已经上传。

若结尾需要品牌全屏卡，先区分已确认 Logo 原文件和候选概念图。最终提示词把收尾卡绑定到对应 `@图片N`；精确字形、商标图形或较长文案优先用原素材做末帧或后期叠加，不把视频模型生成的字形当成可验收的正式 Logo。

### 新视频

```text
【玩法】产品外观参考 + 【具体内容玩法】 + 【生成方式/镜头结构】。
制作【时长、画幅】视频。主题【一句话】。主体【身份或产品】位于【场景】。
【素材说明】@图片1 仅用于【主体外观】；@图片2 仅用于【场景/风格】。没有素材时省略此项。
【时间段/镜头1】起始状态【...】，主体【具体动作】，摄影机【景别/机位/一个主要运镜】，到达【结束状态】。
【后续镜头...】
声音【对白、环境声、音乐职责】。保持【身份、结构、空间、服装、光源等】。避免【与目标直接冲突的问题】。
```

### 图片驱动与多素材参考

先绑定素材编号与职责。图片已给出的外观无需在动作段重复长篇重述；重点写“图片之后发生什么”、前中后景如何变化以及摄影机怎么动。多素材时标注每项继承和不继承的内容，身份/产品优先级高于风格或运镜。

### 首尾帧

说明首帧状态、尾帧状态、可行的中间变化、主体动作和运镜；锁定不变属性。核对两帧比例及平台参数；不要默认模型必然得到精确过渡。

### 编辑与延长

- 编辑：指定原视频和时间段，明确“只改变的对象/属性”与“保持的人物、原动作、背景、机位、灯光、时间节奏、音频”。
- 延长：指定向前或向后、目标时长；从原片**实际**边界状态续接，记录位置、方向、光线、摄影机与声音；列出已完成事件以避免重复。

镜头语言按需要选大远景到微距，以及固定、摇摄、俯仰、轨道进退、跟随、环绕、升降、航拍、POV、焦点转换或甩镜。Zoom 是焦距变化，Dolly 是机位位移。复合运动需说明起终点和动机。
