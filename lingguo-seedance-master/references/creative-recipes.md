# 创意类型与专项配方

先选一个主类型，最多两个辅助类型；“生成方式”另行选择，不把动作迁移、编辑、延长误作内容类型。

## 内容路由

可识别的内容类型：电影剧情、3D CGI、卡通动画、漫画转视频、动作打斗、运动设计广告、电商广告、动漫动作、产品 360 展示、音乐视频、社交媒体钩子、品牌故事、时尚大片、食品饮料、房地产展示、AI UGC、真人口播、产品功能演示、场景替换、超现实视觉奇观、多语言本地化、企业宣传片、教育科普、旅行与自然纪录片。后九类可复用下列专项配方，按实际目的增加口播脚本、功能证据、场景锁定、语言版本、事实来源或自然真实性。

| 主类型 | 导演要点与输出 |
|---|---|
| 电影剧情 | 人物与世界设定、事件因果、情绪变化、场景连续性、节拍与分镜。 |
| 3D CGI | 主体几何与空间比例、材质反射、光线、粒子特效、镜头路径。Blender/Unreal/Octane 仅可作风格描述，不声称模型真的调用了引擎。 |
| 卡通动画 | 明确 2D/3D、角色比例、轮廓、色彩、动作规律、背景与帧间风格。 |
| 漫画转视频 | 先按原漫画阅读顺序抽取人物、场景、对白、动作和关键画面；保持核心剧情与角色身份。 |
| 动作打斗 | 起势→攻击→防守/闪避→反击→结束；给出站位、方向、重心、接触与惯性。复杂打斗分段。 |
| SaaS 与运动设计 | UI、数据、页面转换、设备或功能演示；关键文字、数字与真实界面后期叠加。 |
| 电商广告 | 约 2 秒钩子→亮相→真实卖点→使用场景→价值→CTA；卖点逐项对应用户资料。 |
| 动漫动作 | 角色姿态、速度变化、冲击帧、特效、背景动态与连续性；保持原媒介语言。 |
| 产品 360 展示 | 正面、多角度、材质与细节、英雄镜头；真实产品图锁定外观，复杂旋转分段验证。 |
| 音乐视频 | 分析 Intro/Verse/Chorus/Drop/Bridge/Outro，映射视觉节奏、动作和镜头；精确卡点需分析音频并在后期校准。 |
| 社交媒体钩子 | 视觉反差、结果先行、人物直视镜头、悬念或细节特写；随后安排信息递进。 |
| 品牌故事 | 起源、痛点、解决方案、团队或产品、价值、收尾；历史、客户与认证须有依据。 |
| 时尚大片 | 服装版型/材质、模特走位、布料动态、镜头距离、造型与布光。 |
| 食品饮料 | 食材纹理、切割/倾倒/蒸汽/拉丝、液体流动、微距与环境声；检查物理合理性。 |
| 房地产展示 | 建筑外观、布局、尺寸与空间路径、自然光、材质、室内外衔接；不擅改实际户型。 |

需要“AI UGC/真人口播”时，另写口语化短句、停顿与重音，设计自然表情、眨眼、眼神、呼吸和小幅手势；避免机械播音腔。多语言本地化须逐语种核对台词、字幕和 CTA。产品功能演示、企业宣传、教育科普均要把事实依据与视觉表现分开。场景替换优先保留身份、动作、机位和时间节奏，明确新场景空间关系。
