# 玩法卡库

关卡 1 从这里选卡。每次推荐最多 3 张，并引用客户资料中的依据说明为何适合。

**验证状态说明**：`已验证` = 已用真实 Seedance 输出核对过；`未验证` = 仅基于官方指南与经验推断，风险与回退可能需要修订。新增或修订卡片时必须更新此状态，**不得无依据标为已验证**。

## 卡片格式

```
### 玩法名（复杂度 ★–★★★｜验证：未验证/已验证）
- 一句话效果：
- 适合：（业务类型与目标）
- 客户需提供：（缺则做不了的素材）
- 参考图需求：
- 主要风险：
- 回退做法：
- 提示词骨架：
```

复杂度：★ 预计 0–1 次返工；★★ 1–2 次；★★★ 多次或需分段与后期。

---

### 1. 产品微距钩子（★★｜验证：未验证）
- **一句话效果**：用特写动作（开罐、水珠滑落、倾倒、拉丝）在前 2 秒制造感官钩子，再回到完整产品。
- **适合**：食品饮料、日化、有明显质感或触感的小件商品；信息流广告、种草短片。
- **客户需提供**：清晰的产品正面图；有包装开合结构时需要开合状态图。
- **参考图需求**：产品完整陈列图（锁外观）；一张特写参考图（锁材质，只服务特写镜头）。
- **主要风险**：液体与气泡物理不稳；开合结构变形；特写与整体产品外观不一致。
- **回退**：拆成 2–3 段独立生成再剪辑；特写只保留一个动作；去掉液体飞溅，保留水珠或雾气。
- **提示词骨架**：
  ```text
  制作【时长】竖屏写实产品短片，以图片1为产品外观依据。
  0–2秒：【特写动作与声音钩子】。
  2–【n】秒：摄影机【一个运镜】，主体【起始→结束状态】。
  最后【m】秒：回到完整产品，机位固定，留出后期文字空间。
  声音：【动作声 + 环境声 + 轻音乐】，无口播。保持【产品结构、颜色、光向】。
  ```

### 2. 首尾帧变形转场（★★★｜验证：未验证）
- **一句话效果**：从一个画面平滑变成另一个画面（如产品原料 → 成品，场景 A → 场景 B），用于强视觉冲击或故事转折。
- **适合**：品牌宣传、创意广告、强调“变化”的卖点；需要记忆点的社交钩子。
- **客户需提供**：产品图；若涉及真实原料或场景，需提供对应实拍。
- **参考图需求**：首帧图、尾帧图（比例一致、光向相近），各代表一个时间点。
- **主要风险**：中间过渡不可控；两帧差异过大会出现形变；产品在过渡中结构漂移。
- **回退**：缩小两帧差异；增加一个中间关键帧分两段；用后期转场代替模型内转场。
- **提示词骨架**：
  ```text
  制作【时长】【画幅】视频，首帧为图片1，尾帧为图片2。
  起始状态【...】，主体【可行的中间变化】，摄影机【一个主要运镜】，结束状态与图片2一致。
  保持【不变属性】。声音【...】。
  ```
  （核对平台首尾帧参数与比例要求。）

### 3. 真人口播 UGC（★★★｜验证：未验证）
- **一句话效果**：像真实用户一样对镜头讲产品，短句、自然停顿和轻手势，适合信息流带货。
- **适合**：电商转化、教育科普、产品功能解说；需要“可信感”的场景。
- **客户需提供**：产品图；已确认的卖点文案（有出处）；真人形象需授权，并符合平台人脸规则。
- **参考图需求**：人物身份图（正面与 45 度）、产品图、场景图。
- **主要风险**：口型对不上；手部与产品交互异常；台词中的数字、价格、功效出现事实风险。
- **回退**：台词缩短到每段 1–2 句；口型交给口型工具或后期；产品只在手中静态展示，避免复杂操作；所有数字与价格在后期叠加。
- **提示词骨架**：
  ```text
  制作【时长】竖屏手机拍摄风格的口播视频，人物参考图片1，产品参考图片2。
  人物在【场景】面对镜头，说：“【短句】。”语速自然，句间停顿，眼神看镜头，轻微点头与小幅手势。
  0–2秒：【吸引注意的开场】。后续：【产品展示动作，一个动作一镜】。
  声音：人声清晰，环境声轻。保持人物与产品外观不变。
  ```

### 4. 电商产品图集（★｜验证：未验证）
- **一句话效果**：不做视频，先产出一套统一风格的电商静态图（白底主图、场景图、细节图、多角度图、卖点留白图），也可作为后续视频的参考图。
- **适合**：上架前需要图集的商家；资料里已有实拍图、需要补场景与氛围的客户；想先低成本确认视觉风格再做视频的项目。
- **客户需提供**：至少一张清晰实拍产品图（越多角度越好）；平台图规范（若上架某平台）。
- **参考图需求**：以实拍图为唯一外观依据；每张图只代表一个用途。
- **主要风险**：生成图改变产品细节（标签、接口、比例）；未提供的背面与侧面被“想象”；图内文字乱码。
- **回退**：缺视角的图标注“概念”并建议补拍；文字全部后期叠加；结构变形时降低场景复杂度、回到白底。
- **提示词骨架**：
  ```text
  以输入的图片1为产品唯一外观依据，生成【用途：白底主图/场景图/细节图】。
  产品【逐项锁定的轮廓、颜色、结构、材质、包装】保持不变；场景【空间、台面、道具、光向】；画幅【比例】，留出【位置】的文字空间。
  不得改变产品结构与颜色，不生成文字、Logo、水印或第二件产品。
  ```

### 5. 动作迁移（★★★｜验证：未验证）
- **一句话效果**：用一段参考动作视频驱动指定人物或产品完成同样的动作和节奏。
- **适合**：舞蹈、健身、使用示范、动作类短视频；已有现成动作素材、需换主体的项目。
- **客户需提供**：动作参考视频（有使用授权）；目标人物或产品图。
- **参考图需求**：目标主体身份图；动作视频只承担动作，不承担身份、服装与背景。
- **主要风险**：身份被参考视频带偏；手部与遮挡动作异常；动作过快导致拖影。
- **回退**：缩短到单个动作；选择遮挡少、背景干净的参考视频；动作拆阶段分段生成。
- **提示词骨架**：
  ```text
  动作参考视频1：只继承动作阶段、节奏与位移，不继承人物、服装和背景。
  人物参考图片1：身份与服装的唯一依据。
  【场景】中，人物按视频1的动作依次完成【起始→峰值→结束】，摄影机【一个运镜】。
  保持【身份、服装、光向】。声音【...】。
  ```

### 6. 品牌故事多镜头（★★★｜验证：未验证）
- **一句话效果**：用 3–5 个因果连续的镜头讲一个很短的品牌或产品故事（痛点 → 转折 → 解决 → 收尾）。
- **适合**：品牌宣传、新品发布、企业形象短片；有明确价值主张的客户。
- **客户需提供**：品牌定位、价值主张、可核查的事实；产品图与场景素材。
- **参考图需求**：核心人物与产品身份图；主场景图；风格图。
- **主要风险**：镜头间人物、道具、光线不连续；单段内多次切镜不稳定；剧情事实超出资料。
- **回退**：一镜一段，各段记录计划的起止状态再剪辑；故事压缩到一个因果事件；所有品牌历史与认证只用资料原文。
- **提示词骨架**：每段独立提示词：
  ```text
  片段【n/总数】，【时长】，承接上一段结束状态【...】。
  起始【...】，主体【动作】，摄影机【景别/一个运镜】，结束【...】。
  保持【人物ID、场景ID、道具位置、运动方向】。声音【...】。
  ```

### 7. 产品 360 旋转展示（★★｜验证：未验证）
- **一句话效果**：产品在干净背景中缓慢旋转，或摄影机环绕，展示各面外观，适合上架页和详情页视频。
- **适合**：外观是核心卖点的硬件、饰品、包装类商品；需要全面展示的电商详情页。
- **客户需提供**：正面、侧面、背面等多角度实拍图（缺哪面，哪面就只能标“概念”）。
- **参考图需求**：各角度实拍图；一张干净背景英雄图。
- **主要风险**：旋转过程中产品结构变形；背面与侧面被模型臆造；旋转角度过大。
- **回退**：只做 90–180 度的小角度环绕；拆成多段（正→侧、侧→背）后期拼接；缺视角则不展示或标注概念。
- **提示词骨架**：
  ```text
  制作【时长】【画幅】产品展示视频，产品外观以图片1–【n】为准，背景【干净/石台】，光线【主光方向、柔光】。
  摄影机【环绕/产品匀速旋转】【角度范围】，速度缓慢匀速，产品始终居中、完整入画。
  保持【轮廓、颜色、接口、材质】不变。声音【轻音乐/静音】。
  ```

### 8. 场景替换（★★｜验证：未验证）
- **一句话效果**：保留原视频的人物动作、机位和节奏，把背景或场景换成另一个环境。
- **适合**：已有可用视频素材、需要多版本场景的投放；节日、地区、季节版本。
- **客户需提供**：原视频（有授权）；目标场景图或文字描述。
- **参考图需求**：新场景图（空间布局与光线）；必要时原视频关键帧作对照。
- **主要风险**：人物与新场景的光线、阴影、接触关系不合；人物身份与动作被改变；边缘残留。
- **回退**：缩短编辑时段；只替换背景，不替换人物与道具；加强光向和空间锚点描述。
- **提示词骨架**：
  ```text
  编辑视频1【时间段】。只替换：【背景/场景】为图片1所示的【描述】。
  保持不变：人物身份与服装、原动作、机位、时间节奏、音频。
  新场景的光线方向与色温与人物一致，接触与阴影合理。
  ```
