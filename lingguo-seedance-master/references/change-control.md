# 变更控制：先锁定，后可调

目的：开头把方向钉住以减少返工，但仍允许后期调整，并让每次调整可预期、可追溯。

## 锁定分级

| 级别 | 内容 | 要改时 |
|---|---|---|
| **红线** | 客户事实与出处、品牌与合规限制、平台规格、授权范围 | 必须由客户或用户本人明确确认；AI 不得自行修改 |
| **方向** | 玩法、核心概念、主视觉风格、主要卖点取舍 | 退回关卡 1 重新确认，之后的产物按下表重做 |
| **可调** | 节奏、时长分配、运镜、景别、光线细节、声音、字幕与文案、个别镜头 | 在对应关卡内直接修改 |

## 影响范围表

| 用户说要改 | 要重做 | 不用重做 |
|---|---|---|
| 换玩法 | 关卡 1 起全部 | 关卡 0 的资料分析 |
| 换主风格、色调 | 全部参考图 + 视频提示词 | 玩法与事实 |
| 某张参考图不满意 | 该图及依赖它的镜头 | 其他图 |
| 增删参考图范围 | 素材地图及相关提示词 | 已确认的图 |
| 节奏、运镜、光线、声音 | 仅视频提示词（及分镜） | 参考图 |
| 时长或画幅变化 | 分镜与视频提示词；参考图视比例是否需重出 | 玩法、事实 |
| 文案、价格、CTA | 后期叠加内容与相关提示词中的留白说明 | 视频内容 |
| 客户事实更新 | 受影响的全部产物，并重新自检 | 无关镜头 |
| 平台或模型变更 | 引用语法、参数与分段方案，并重新核对平台能力 | 创意方案 |

## 调整流程

1. 先复述用户的要求，归入上表某一行。
2. **在动手前**列出：改动级别、受影响的产物、预计重做内容与不变内容。
3. 用户同意后执行。若改动触及“方向”或“红线”，明确提示并等待确认。
4. 在 `decisions.md` 追加一条变更记录（日期、原决定、新决定、原因、受影响产物）。
5. 一轮只处理一批相关修改；已确认且未受影响的产物不重新生成。

## 实际成片反馈

拿到实际生成结果后，按“问题 → 可能原因 → 本轮只改的一个变量 → 新结果”记录；常见问题与优先试验见 `production-and-delivery.md` 末尾。没有成片时不写成片验收结论。
