# 两阶段创意与提示词交付

## 第一阶段：供确认的完整方案

把用户的原始资料转成可以选择、可以审核的方案，而非只列风格词。按内容复杂度包含：

1. **资料分析**：已确认事实及出处、传播目标、受众、平台、现有素材、关键限制、暂定假设。资料没有的功能、数据、客户、认证和效果不能当作卖点。
2. **创意方向比较**：每个方向给一句话概念、开头钩子、画面/叙事机制、Seedance 玩法、具体视觉风格、需要的素材、稳定性难点及适用目标。方向之间应有真正的表达差异。
3. **推荐方案展开**：说明推荐理由、时长与画幅、开场到结尾的节拍、关键镜头画面、角色/产品/场景锁定、声音与字幕方法、素材制作清单、预期可见效果。用户应能判断“做出来大概是什么样”。
4. **确认节点**：只请用户确认推荐方向、选择另一方向或给出一轮修改。用户回复已清楚表达选择或批准后，直接进入第二阶段；不再为每张素材图或每个镜头逐次请求许可。

若用户一开始已经给出明确创意并授权直接做提示词，视为方案已确认；先简要复述执行假设，再完成第二阶段。若用户只是要一个简短提示词，按其请求范围完成即可。

## 第二阶段：最终提示词包

按实际任务省略无用部分；最终内容应让操作者按顺序拿去制作：

1. **确认的创意与制作参数**：一句话概念、目标平台/模型、时长、画幅、语言与声音；未指定平台时标明需替换引用语法。
2. **素材地图**：已有/待生成、编号、主职责、继承/不继承、锁定对象、作用镜头、优先级。不要把素材生成提示词和 Seedance 视频提示词混成一段。
3. **素材生成提示词或制作指令**：仅为所需人物、产品、场景、风格、关键帧、动作/运镜参考视频或音频分别给出完整可复制文本；标注用途、规格、参考输入和必须保持的属性。真实产品缺少相应视角时给补拍说明或标明概念，不把推测外观当作真实商品。
4. **分镜表与连续性计划**：按下文格式写镜头任务和起止状态。
5. **Seedance 主提示词**：一个完整代码块，包含素材绑定、时间轴、动作、运镜、光线、声音、连续性和必要的排除项。多次提交才增加每段独立提示词及顺序。
6. **提交说明与自检**：素材上传顺序、模式/参数选择、平台需确认的限制、已自检的项目、仍需客户确认的关键事实。

交付时直接给出最终可复制文本。只报告实质性的未解决问题，不把自检工作变成用户的待办清单。

## 分镜表

按项目规模填写：`镜头/时间｜镜头目的｜起始状态｜主体动作｜结束状态｜景别与机位｜主要运镜｜光线变化｜声音｜素材绑定`。每镜头有一个主要运镜；复杂复合运动需解释起点、终点与动机。避免只罗列漂亮画面而没有叙事作用。

## 连续项目计划表

多镜头、多段或延长项目记录 `Project ID、Character ID、Scene ID、Clip ID、Parent Clip、Opening State、Ending State、Completed Beats、Reserved Beats、Continuity Locks`。在提示词阶段，Opening/Ending State 是**计划状态**；已有视频作为输入时，读取实际结束姿态、位置、道具、运动方向、镜头、灯光与音频后再写延长提示词。不要把计划状态写成已生成的事实。

## 交付前提示词自检

检查主提示词是否可直接复制；素材生成提示词是否分别对应素材地图；素材编号、用途和平台引用方式是否清楚；时长与时间轴是否相加吻合；各镜头起止状态是否连续；人物、产品和场景锁定是否冲突；对白、音效、字幕是否各有职责；商业事实是否有来源；推荐玩法与当前平台能力是否匹配。需要分段生成时，每段必须有独立提示词，不能让用户从分析中自行拼接。交付中明确哪些是已确认资料、哪些是暂定假设。

## 实际生成后的反馈（仅在用户另行要求时使用）

看到模型输出后再检查主体与产品结构、动作与接触、场景空间、光线、镜头、音画、文字、开头吸引力、信息准确性和结尾 CTA。记录 `问题 → 可能原因 → 本轮只改的主变量 → 新结果`。

| 观察到的问题 | 优先试验 |
|---|---|
| 人物变脸/身份漂移 | 加强身份图绑定、缩小转头幅度或缩短片段。 |
| 产品变形 | 补细节/多角度真实产品图，减少大角度旋转。 |
| 动作僵硬/手部异常 | 拆动作阶段与重心，简化手势或调整遮挡。 |
| 场景跳变/光线错位 | 加空间锚点或固定主光方向与色温。 |
| 运镜错误 | 只留一个主要运镜，明确起止构图。 |
| 口型/音画不同步 | 缩短台词，优化停顿，使用可用口型工具或后期校准。 |
| 文字乱码 | 用真实 UI 或后期叠字。 |
| 画面缺乏重点 | 重定镜头任务与主体动作。 |

没有实际生成时，上表只是后续修改参考，不写成成片验收结果。只有看到最终视频才可判断成片质量。

## 企业项目交付

按项目需要交付以下内容，避免机械填空：

1. 客户业务理解与可核查的卖点来源。
2. 创意方案、主/辅助类型、目标平台和规格假设。
3. 素材准备清单、各素材继承/不继承/优先级；必要的参考图提示词。
4. 分镜脚本、主提示词与需要分段提交的分镜提示词。
5. 提交时的平台设置、素材上传顺序、提示词自检结果，以及尚待客户确认的事实或素材。
6. 客户展示版保留创意、分镜和关键画面描述；内部制作版保留素材编号、参数、提示词与版本。

后期剪辑、发布建议、提交记录和成片质检仅在用户要求继续制作时增加。

## 课堂演示

触发示例：`课堂演示：产品广告/动作迁移/真人口播/3D CGI/漫画转视频/音乐视频`。默认顺序为：讲玩法 → 展示现有素材及作用 → 生成所需参考图提示词 → 分镜 → 可复制提示词 → 说明如何提交 → 总结可复用方法。用户明确要求课堂实操时才继续提交、看结果、单变量修改和前后对比；没有模型或样片时不虚构播放与对比。
